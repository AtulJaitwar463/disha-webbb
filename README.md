# Disha Sonkar — Global Learning & AI Solutions

Website repository: `disha-webbb`.

Responsive React website for Disha Sonkar's mentorship, learning, and digital
solutions services.

## Run locally

```sh
npm install
npm run dev
```

## Connect enquiries

The contact form opens a prefilled email in the visitor's default email app.
Before publishing, copy `.env.example` to `.env.local` and set
`VITE_CONTACT_EMAIL` to Disha's preferred enquiry email. Without it, the form
clearly reports that delivery is not configured.

## Verify and build

```sh
npm run lint
npm run build
```

The published copy uses the supplied brochure's 60+ learners-and-clients figure
and describes the 16 countries as locations named in the current brief, not as
an audited client count.
